# Example list for the tvDebloat Gradle task (see docs/DEVELOPMENT.md).
#
# Copy this file to tv-debloat.txt (git-ignored) and remove the leading "#" from the packages you
# want to switch off. One package name per line; everything after "#" is a comment.
#
# tvDebloat runs "pm disable-user --user 0 <package>" for each line: the app is switched off, not
# removed. tvRestoreStock (or a factory reset) re-enables every package listed here plus the stock
# launcher.
#
# Be conservative. Run tvReport first and only disable packages you recognise. Package names differ
# between devices and firmware versions; names that are not installed are skipped.
#
# NEVER disable (Halo or the TV needs them):
#   com.google.android.katniss          Google voice input; Halo's "Ask Halo" uses it for speech recognition
#   com.google.android.tts              text-to-speech (Halo's fallback voice)
#   com.google.android.gms / .gsf       Google Play services
#   com.android.vending                 Play Store (updates)
#   com.google.android.tvsetup / com.google.android.tungsten.setupwraith  setup (use tvMakeHaloDefault instead)
#   anything with "bluetooth", "remote", "inputmethod", "systemui", "settings" or "provider" in its name
